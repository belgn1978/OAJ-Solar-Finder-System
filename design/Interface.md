# Interface Design

## Purpose

The interface is the heart of the OAJ Solar Finder System.

Every telescope adapter connects to the main body using exactly the same interface.

This means the main body never needs redesigning when supporting a new telescope.

---

## Design Goals

- Universal connection
- Easy to print
- Strong
- Minimal supports
- Beginner friendly
- Replaceable adapters

---

## Version

Current Version: P1

---

## P1 specification

- Captured male dovetail on each telescope adapter
- Rear-entry female socket in the universal body
- 22 mm engagement length
- 16 mm neck width and 20 mm head width
- 4.5 mm dovetail height
- 0.25 mm clearance per side
- Positive front insertion stop

---

## Future Improvements

- Locking button or clip after physical fit testing
- Magnetic retention
- Quick release
